# Rank 102 — Real-Time Control of Six-DOF Serial Manipulators via Learned Spherical Kinematics
状态：READ_COMPLETE
全文：[MDPI indexed full article](https://www.mdpi.com/2218-6581/15/1/27)。
1. 基本信息：Meher Madhu Dharmana, Pramod Sreedharan；2026；Robotics 15(1):27；DOI 10.3390/robotics15010027。
2. 具体问题：球腕 6-DOF 机器人需要低延迟、多解且在奇异附近稳定的 IK；纯解析法易受建模误差影响，LM/DLS 依赖初值和迭代。
3. 机器人/DOF/冗余：KUKA Rhino 6-DOF spherical-wrist serial manipulator，非冗余，具有最多 8 个离散姿态分支。
4. 方法核心：前三个位置关节在球坐标中用低阶多项式拟合，末三腕关节用闭式解析解；随后用 spherical-coordinate error 的 partial-derivative 逐分量迭代修正，不构造完整 Jacobian。
5. IK 方法/求解器：polynomial learned approximation + wrist closed-form + iterative partial-derivative refinement；对比 LM、DLS、fmincon。
6. multiple IK solutions：是；系统枚举每个目标最多 8 个有效解，并丢弃越限/发散候选。
7. branch selection/tracking/switching：没有自动 branch selection 标准；future work 明确要建立 criteria-based branch selection。
8. singularity avoidance/crossing/transition：动机和修正步骤关注奇异邻域、丢弃发散解；没有严格奇异规避/穿越证明。
9. joint constraints：丢弃超出关节范围的候选；未处理速度、加速度或扭矩约束。
10. collision/obstacle：未涉及。
11. 层级：pose-level 多解 IK，并用于实时控制/轨迹点序列。
12. sampled/discrete path：是；目标姿态和轨迹点逐点求解，离散控制更新。
13. 连续性/可执行性保证：迭代修正和候选过滤改善误差，但没有 branch continuity 或连续时间执行保证。
14. offline/online：多项式拟合离线，修正和多解推理在线，目标毫秒级控制。
15. simulation/real：KUKA Rhino 仿真/数值 benchmark；搜索摘要未显示真实硬件闭环，按可读正文范围记录为仿真验证。
16. 主要实验和结果：与 LM、DLS、fmincon 比较；最多 8 解、较高精度和多分支覆盖，约比 fmincon 快 8.1×。正文报告该自定义混合方法在误差、速度和多解覆盖上优于优化 baseline。
17. 主要贡献：利用球腕结构把学习近似限制在前三关节，保留腕部解析结构，减少模型规模并提升外推/实时性能。
18. 主要局限：针对特定球腕和一条轨迹/机器人；多项式受 workspace/calibration 影响，未处理碰撞、轨迹连续和实机误差。
19. 作者 future work：不确定性传播、适配非球腕结构、基于准则的自动 solution-branch selection。
20. TCIK 一句话：它是快速八分支混合 IK，但 branch continuity 和实际机械臂可执行性仍未被证明。
