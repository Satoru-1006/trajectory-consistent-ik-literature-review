# Rank 76 — Automatic Geometric Decomposition for Analytical Inverse Kinematics
状态：READ_COMPLETE
全文：[arXiv full text](https://arxiv.org/pdf/2409.14815)；IEEE RA-L 版本核对 DOI。
1. 基本信息：Daniel Ostermeier, Jonathan Külz, Matthias Althoff；2025；IEEE Robotics and Automation Letters 10(10):9964–9971；DOI 10.1109/LRA.2025.3597897；arXiv:2409.14815。
2. 具体问题：如何针对不同几何的串联机械臂自动生成可靠、快速的解析 IK，避免手工符号推导的耗时和数值不稳定。
3. 机器人/DOF/冗余：主要覆盖 1–6 个转动关节的非冗余串联臂；示例含 UR5、PUMA、ABB IRB6640、虚构 3-parallel/ spherical 机构，以及将 Panda 的末端关节锁定后的 6R。冗余机械臂通过锁定关节处理，不是完整冗余求解。
4. 方法核心：先自动重定位关节轴参考点并重塑运动链，分类运动学结构，再把链分解为 Elias 稳定子问题；必要时反转链，用几何子问题组合求解。作者实现 EAIK 的 C++/Python 工具链。
5. IK 方法/求解器：解析几何子问题求解（圆/球交、线性代数和特征问题），由自动分解器生成闭式计算代码；奇异或无有限精确解时使用稳定的最小二乘子问题。
6. multiple IK solutions：是。算法返回给定姿态的完整解析可行解集合，而不是单个数值初值解。
7. branch selection/tracking/switching：会过滤不可行解，但没有时间序列 branch 标签、跟踪或主动切换策略。
8. singularity avoidance/crossing/transition：稳定子问题可在局部奇异或工作空间边界保持数值稳定，论文未给出全局奇异穿越或轨迹转换保证。
9. joint constraints：没有在 IK 内联合优化关节位置、速度或加速度；关节范围等约束需要对完整解做后验检查。
10. collision/obstacle：没有内生碰撞或障碍约束，仅可在外部运动规划器中后验验证。
11. 层级：pose-level 解析 IK 和随机姿态批量计算；不是路径或时间轨迹优化器。
12. sampled/discrete path：没有路径级求解；实验是随机离散姿态采样。
13. 连续性/可执行性保证：作者讨论稳定子问题的局部连续性，但没有给出跨姿态的 branch continuity、全局连续或硬件可执行性证明。
14. offline/online：每个机械臂的分解/代码生成是离线的；生成代码可在线快速求单姿态 IK。
15. simulation/real：CPU 数值实验与模型仿真；没有真实机器人闭环实验。
16. 主要实验和结果：每个模型约 5000 个随机姿态，并另测 10000 个随机 6R 姿态。EAIK 推导/求解约 35–45 μs；UR5 约 39 μs，而对照符号/数值方法可达毫秒至分钟。位置误差通常约 1e−15 m；Panda 中位位置误差约 1.12e−15 m，IKFlow 约 7.3e−3 m；整体通常比 IKFast 快至少约 5 倍（个别 PUMA/Panda 情况例外）。
17. 主要贡献：把运动学重塑、结构分类、稳定几何子问题和代码生成自动化，提供跨多种 6R 几何的快速完整解析 IK。
18. 主要局限：不覆盖并联链、非转动关节、多末端；冗余通过锁定关节规避；关节限制、轨迹一致性、碰撞等需要后验处理，复杂问题仍有运行时和内存代价。
19. 作者 future work：为未知运动学类别加入半数值 fallback；支持显式冗余参数化、线性/并联关节和更广泛机构。
20. TCIK 一句话：这是高质量的多解 pose-level 解析 IK 生成器，但没有 branch tracking、路径连续性、碰撞或轨迹级可执行性保证。
证据：完整 PDF 的 Sec. II–VI、算法和表格；身份由 DOI、RA-L 题名和 arXiv 版本核对。
