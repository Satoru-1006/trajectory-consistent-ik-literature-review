# Rank 63 — Direct Collocation Methods for Trajectory Optimization in Constrained Robotic Systems

状态：READ_COMPLETE
全文：[arXiv PDF](https://arxiv.org/pdf/2304.12908)；正式出版 IEEE Transactions on Robotics 39(1)，2023，DOI 10.1109/TRO.2022.3193776；已读全文正文、§§I–VIII、Tables I–IV、Figs. 1–16 与 Appendix（参考文献除外）。

1. 基本信息：Ricard Bordalba、Tobias Schoels、Lluís Ros、Josep M. Porta、Moritz Diehl；2023，IEEE Transactions on Robotics 39(1)；DOI 10.1109/TRO.2022.3193776；arXiv:2304.12908。
2. 具体问题：直接配点/轨迹优化在含闭环、非完整约束的机器人系统上会产生约束流形漂移；比较并改进 basic、Baumgarte、PKT、projection 和 local-coordinates transcription，使优化轨迹保持在非线性约束流形上。
3. 机器人：示例包括五杆平行机器人（5 个转动关节、2 个驱动）、四轮 Mecanum 车（车体 3 自由度+4 轮角，4 个轮力矩输入，非完整约束）以及两台 Franka Emika 7-DOF 臂协同搬运气瓶（14 个关节、6 个闭环约束）；其中双臂系统是冗余/高自由度场景，但论文不是通用冗余 IK 求解器。
4. 方法核心：在状态流形 X={x:F(x)=0} 上做 direct collocation。projection 方法把每个配点终态正交投影回 X；local-coordinates 方法在 X 的局部坐标/切空间中配点，再用局部参数化映回流形，从而整段连续样条保持无漂移；并比较 Baumgarte 人工稳定项与 PKT 中点松弛的副作用。
5. IK 类型：不是 pose-level IK；是含动力学、控制和代数约束的 direct trajectory optimization/collocation。初始猜测可由满足约束的 kinodynamic planner 或粗网格 projection warm start 提供。
6. Multiple solutions：优化器和投影射线在流形上可能有多个交点，作者通过距离惩罚选择离投影点最近者；局部最优依赖初始猜测，未枚举机械臂完整 IK 多解集。
7. 分支：未提出 IK branch tracking/switching；局部坐标图和最近投影有助于保持局部连续，但不同流形分支/同伦类由初始猜测决定，不做全局分支搜索。
8. 奇异性：假设约束 Jacobian 满秩、流形维数局部恒定；因此方法在建模层面避开约束流形奇异。文中提到 constrained robot 的 forward singularities 会妨碍逆动力学初值，并建议随机 kinodynamic planner 跨越它们；没有证明奇异穿越。
9. 约束：处理 holonomic/nonholonomic 约束、动力学、闭环、轮胎无滑移、边界/路径约束及电机力矩界；双臂示例受驱动力矩和末端静止边界约束，代价用控制平方或控制导数平方促进平滑。速度/加速度来自动力学变量，未建立普适的工业 joint-limit/jerk 安全证书。
10. 碰撞：一般 formulation 允许路径约束加入碰撞条件，但三组数值示例主要展示闭环/非完整流形漂移，不报告碰撞几何或 obstacle-avoidance 实验。
11. 层级：trajectory-level direct collocation；不是单 pose IK，也不是仅离散 waypoint 选择。输出是带控制/动力学的连续时间样条近似。
12. 离散性：优化在 N 个时间区间和 Gauss–Legendre 配点上离散；local-coordinates 方法再以局部参数化构造连续 spline。离散 NLP 仍需数值误差评估，不能把配点约束自动当成任意点严格约束。
13. 连续性/执行保证：local-coordinates 方法按构造使 spline 全程落在 X，projection 只保证 knot states、区间内仍有漂移；作者定义并积分运动学误差 EK 与动力学误差 ED。该保证是光滑流形与数值模型下的几何/离散化性质，不是碰撞、硬件、全局最优或 IK branch 可执行性证明。
14. Offline/online：离线数值轨迹优化；MacBook Pro Intel i9 求解，未展示在线控制周期或实机闭环。
15. Simulation/real robot：三个系统均为仿真/数值优化（平行五杆、Mecanum 车、双 Franka 模型）；没有真实机器人实验。
16. 主要实验：五杆举重中 basic 漂移导致机构解体，Baumgarte 仍有轻微解体，PKT/projection 只在 knot 间有微小解体，local coordinates 消除连续解体；Mecanum 圆路径中 local coordinates 的 EK 约 10^-13，d=4 时 ED 约 0.2，而 basic/projection 仍有明显 EK；双 Franka 搬运中 N=42、Δt=.04 s，local coordinates 在 d=3/4 达 EK 约 10^-14、ED 约 .15/.04，并与 projection warm start 形成高效管线。所有解是局部优化结果。
17. 贡献：将几何积分/局部坐标推广到一般约束机器人 direct collocation；提出 projection 与 local-coordinates 两种无漂移 transcription，支持任意配点多项式和 hp-adaptive mesh，并量化运动学/动力学误差。
18. 局限：local coordinates 计算更贵且需连续更新切空间基；QR 基不唯一、邻近点可能不平滑，需 Gram–Schmidt 更新；局部最优依赖初值；projection 区间内仍漂移；论文没有碰撞实验、实机验证、全局最优或全局 IK 分支保证。
19. Future work：结论明确指出复杂系统可改进初值，并建议研究将所提方法作为全局 asymptotically-optimal planner 的 steering method，使局部连接同时满足运动学和动力学约束。
20. TCIK 一句话：该文提供的是约束轨迹优化的连续流形配点工具，local-coordinates 可消除整段动力学轨迹的流形漂移，但它不解决多 IK 分支枚举/选择，也不提供碰撞安全或全局可执行保证。

证据：§§II–IV 的约束流形、basic/Baumgarte/PKT；§V projection/local coordinates；§VI 边界、初值和误差；§VII Figs. 10–16 与 Tables II–IV；§VIII Conclusions。作者明确区分 knot-only projection 与 full continuous-time local-coordinate drift elimination，并明确声明最终轨迹是给定初值同伦类中的局部最优。
