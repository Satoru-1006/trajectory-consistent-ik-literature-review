# Rank 81 — Real-time inverse kinematics for robotic manipulation under remote center-of-motion constraint using memetic evolution
状态：READ_COMPLETE
全文：[OUP full article](https://academic.oup.com/jcde/article/11/3/248/7684300)。
1. 基本信息：Ana Davila, Jacinto Colan, Yasuhisa Hasegawa；2024；Journal of Computational Design and Engineering 11(3):248–264；DOI 10.1093/jcde/qwae047。
2. 具体问题：在手术器械远程中心运动（RCM）约束下，实时求解冗余机械臂的末端姿态和工具约束 IK。
3. 机器人/DOF/冗余：KC-1 为 7-DOF 机械臂加 3-DOF 工具（有效 9 DOF，夹爪 DOF 不进 IK）；KC-2 为 7+5（有效 11 DOF，夹爪 DOF 排除）。相对 RCM+末端任务高度冗余。
4. 方法核心：PivotIK 将 memetic evolutionary algorithm 与分层 Jacobian 局部精化结合；适应度同时惩罚 RCM 和末端位姿误差，利用 Moore–Penrose/null-space 更新，在种群中保留精英并做局部搜索。
5. IK 方法/求解器：进化种群搜索 + Jacobian 分层局部优化；对比 nonlinear optimization（NLO）和 hierarchical quadratic programming（HQP）。
6. multiple IK solutions：种群同时探索多个候选，但输出一个精英解；不是穷举或离散解析分支集合。
7. branch selection/tracking/switching：没有 branch 标签、时间跟踪或切换规则。
8. singularity avoidance/crossing/transition：讨论 Jacobian 方法的奇异鲁棒性和 RCM 约束，但没有奇异面穿越或连续转移证明。
9. joint constraints：NLO/HQP 直接加关节上下界；PivotIK 初始化种群在关节范围内，未建模速度/加速度硬约束。
10. collision/obstacle：未处理；结论把碰撞避免和可操作度列为遗漏事项。
11. 层级：pose-level 受约束 IK，并用于路径/时间序列跟踪。
12. sampled/discrete path：是；250 个随机 U-3D/U-6D/C-RCM 姿态，另有 2500 点 6D Lissajous 序列。
13. 连续性/可执行性保证：Reflexxes 轨迹生成器提供在线关节平滑和速度连续；PivotIK 本身没有数学连续性或全局可行性保证。
14. offline/online：在线求解，目标是亚毫秒级实时更新。
15. simulation/real：CoppeliaSim/Pinocchio/PyGMO 仿真，另有真实 9-DOF 机械臂 Lissajous 实验。
16. 主要实验和结果：PivotIK 在 KC-1/KC-2 的三类随机任务求解率 1.0；优化 C++ 在 helix 约 0.75±0.40 ms、hypotrochoid 约 0.45±0.21 ms，优于 NLO 约 2.02/1.61 ms 和 HQP 约 1.02/0.69 ms。实机 2500 点序列 100% 成功，约 1.55±0.46 ms；RCM 偏差均值约 1.7 mm、最大约 3 mm。
17. 主要贡献：把全局种群探索与局部分层 Jacobian 结合，在 RCM 冗余手术任务中获得较高成功率和实时速度，并做真实机械臂验证。
18. 主要局限：约束集合仍较窄，碰撞/可操作度未纳入；没有并行进化加速；误差权重对结果影响未系统分析。
19. 作者 future work：增加碰撞和可操作度约束、进化并行化、扩展真实部署，并进一步研究权重设计。
20. TCIK 一句话：这是在线冗余约束 IK 的实时实机验证，但多候选并不等于 branch tracking，连续性主要来自外部 Reflexxes 平滑器。
证据：OUP HTML 的方法、表 2–5、真实 Lissajous 实验、Discussion/Conclusion。
