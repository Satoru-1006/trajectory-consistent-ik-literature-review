# Rank 73 — Singularity-Robust Inverse Kinematics for Serial Manipulators

状态：READ_COMPLETE
全文：[JAMRIS 开放 PDF](https://reference-global.com/download/article/10.14313/jamris/3-2023/21.pdf)；已读全文 §§1–7、Eqs. (1)–(54)、Figs. 1–3 与结论。

1. 基本信息：Ignacy Dulęba；2023，Journal of Automation, Mobile Robotics and Intelligent Systems 17(3):38–45；DOI 10.14313/JAMRIS/3-2023/21。
2. 具体问题：比较并评估 additive、multiplicative 和 SVD-based robust inverse，使 Newton IK 在 serial manipulator singular/near-singular configuration 下保持可计算，并分析路径通过奇异时的误差。
3. 机器人：理论覆盖 n-DOF serial manipulator；实验采用 3-DOF 位置型机械臂模型，任务空间 m=3，非冗余。
4. 方法核心：Newton IK 使用伪逆；方法 1 在 manipulability 矩阵加 λI；方法 2 乘性扰动；方法 3 对小奇异值设置统一下限 d_min 的 SVD robust inverse。将 singularity detection 与 inverse construction 合并。
5. IK 类型：迭代 Newton/Jacobian 数值 IK；SVD 或 manipulability matrix 作为逆的稳健化。
6. Multiple solutions：不枚举 multiple IK solutions；局部 Newton 收敛依赖初值。
7. 分支：无 branch tracking/switching；只处理矩阵逆和运动方向，不提供全路径分支身份。
8. 奇异性：核心内容。用 rank/corank、det(JJᵀ)、最小奇异值检测；SVD 将小于 d_min 的奇异值替换为 d_min，能在边界/内部奇异附近继续迭代。指出奇异任务方向不可实现，鲁棒逆只能近似，不能创造失去的运动自由度。
9. 约束：只考虑末端误差阈值和 SVD 阈值/步长；没有 joint position/velocity/acceleration/torque/collision 约束。
10. 碰撞：未处理。
11. 层级：pose/path-level 数值 IK；示例为沿时间路径连续求 pose，非动力学 trajectory optimizer。
12. 离散性：Newton 迭代和时间路径均离散采样；无连续时间证书。
13. 连续性/执行保证：3-DOF 奇异路径上两种 robust 算法几乎相同，SVD 方法能在末端边界达到指定误差而普通加法法停在 5.6×10^-6；这属于数值仿真效果，没有 branch、碰撞或硬件执行保证。
14. Offline/online：数值 IK 可在线迭代；本文比较为离线仿真。
15. Simulation/real robot：3-DOF 数值机械臂仿真，无实机。
16. 主要实验：参数 a1=.3、a2=.2、a3=.3，奇异检测 d_m<10^-3、修正下限 d_min=10^-2；路径 x=y=0、z 随时间变化且全程 A=0，位于奇异构型。两算法的 q1≈300°，SVD 在最终 corank-2 边界达到 δ=10^-9，普通法距目标 5.6×10^-6。
17. 贡献：给出 robust inverse 的矩阵理论、几何解释和多指标评价，推荐统一下限 SVD 作为计算简单且适用于冗余/非冗余的基线。
18. 局限：SVD threshold 是设计参数；运动方向缺失时必有跟踪误差；局部 Newton、无全局分支/约束/碰撞；只有小型仿真，不能外推到实机安全。
19. Future work：正文没有单独列出 future-work 计划；讨论了参数标定、归一化、可实现/不可实现方向等实践问题。
20. TCIK 一句话：SVD robust inverse 能在数值上接近或穿过某些奇异路径，但它不生成缺失方向，也不证明 IK branch 连续或约束可执行。

证据：§2 Newton/伪逆；§§3.1–3.4 additive、multiplicative、SVD；§4 评价标准；§5 3-DOF 仿真；§6.4 不可实现方向；§7 结论。
