# Rank 104 — UR3 Collaborative Robot Inverse Kinematics Using Metaheuristic Optimization: A Unified Comparative and Experimental Evaluation
状态：READ_COMPLETE
全文：[MDPI full article](https://www.mdpi.com/2571-5577/9/7/140)。
1. 基本信息：Julio Antonio Caballero-Mora, Daniel Sanin-Villa, Huber Girón-Nieto, Vanessa Botero-Gómez, Rogelio de Jesús Portillo-Vélez, Janet Carolina López-Romero, Juan C. Tejada；2026；Applied System Innovation 9(7):140；DOI 10.3390/asi9070140。
2. 具体问题：在相同计算预算和目标下，系统比较 PSO、GWO、GA、JADE、ALO 与 LM 的 UR3 全位姿 IK，特别考察近奇异姿态的准确性、稳定性和运行时间。
3. 机器人/DOF/冗余：UR3 6-DOF 协作串联臂，非冗余；不同 metaheuristic basin 产生多种候选但任务没有冗余 DOF。
4. 方法核心：以物理缩放的 position+orientation matrix residual 为统一目标，加入平滑 Jacobian-conditioning penalty；五种零阶算法统一种群/迭代设置，LM 作确定性基线，RoboDK 与实机做验证。
5. IK 方法/求解器：PSO、Grey Wolf (GWO)、GA、JADE、Ant Lion Optimizer (ALO) 与 Levenberg–Marquardt；不是解析多解求解器。
6. multiple IK solutions：随机算法会探索多个局部候选，但最终每次返回一个配置；没有完整 branch enumeration。
7. branch selection/tracking/switching：连续多姿态实验使用前后解/统一任务序列检验 sequential stability，但无明确 branch ID 或切换状态机。
8. singularity avoidance/crossing/transition：显式 Jacobian conditioning penalty 抑制病态区域，near-singular pose 是 benchmark；没有奇异穿越保证。
9. joint constraints：统一使用关节 bounds；未处理速度、加速度、jerk 或扭矩约束。
10. collision/obstacle：benchmark 无障碍 IK；RoboDK 验证几何可执行性，但不是障碍规划。
11. 层级：pose-level IK，多姿态序列 tracking 验证。
12. sampled/discrete path：是；每姿态 1000 Monte Carlo runs，连续轨迹由离散多 pose 组成。
13. 连续性/可执行性保证：conditioning penalty 与序列验证只提供经验稳定性；没有完整轨迹连续性、全局最优或连续时间安全证明。
14. offline/online：离线 MATLAB/RoboDK benchmark；代表性 GWO 解经 TCP/IPv4 发送给真实 UR3。
15. simulation/real：RoboDK 虚拟环境和真实 UR3 静态姿态、连续 multi-pose trajectory 实验。
16. 主要实验和结果：nominal、industrial、near-singular 三姿态各 1000 Monte Carlo。LM 速度/精度最佳；GA 的平均 objective 和 dispersion 最低，JADE 最快，GWO 在精度与时间间折衷。近奇异时 GA mean objective 0.267、σ=0.060，GWO mean 0.346/0.80 s，JADE 0.10 s 但 mean 0.438；GWO 代表解在 RoboDK 和真实 UR3 多姿态执行成功。
17. 主要贡献：给出统一残差、conditioning penalty、统计 rank-based 比较、仿真+实机可复现评价协议，而非再提出一个变体算法。
18. 主要局限：单一 UR3、无障碍/动力学/多分支完整性；metaheuristic 仍有随机性，LM 在标准精确模型下占优。
19. 作者 future work：正文未列出独立 future-work 章节；本文明确定位为 benchmark，因此不推断未写出的扩展。
20. TCIK 一句话：它提供近奇异 pose-level IK 的严谨横向 benchmark 和实机检查，但没有 branch tracking 或轨迹级连续性保证。
