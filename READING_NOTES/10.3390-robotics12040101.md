# Rank 65 — Inverse Kinematics of an Anthropomorphic 6R Robot Manipulator Based on a Simple Geometric Approach for Embedded Systems

状态：READ_COMPLETE
全文：[Robotics 正式开放 PDF](https://www.mdpi.com/2218-6581/12/4/101/pdf?version=1689148031)；已读全文 §§1–8、Appendices A–B、Tables 1–4 与 Figs. 1–16。

1. 基本信息：Michael Anschober、Raimund Edlinger、Roman Froschauer、Andreas Nüchter；2023，Robotics 12(4):101；DOI 10.3390/robotics12040101。
2. 具体问题：为资源受限嵌入式控制板设计计算量低、数值精度高的 anthropomorphic 6R 球腕 IK，用于搜索救援移动机械臂。
3. 机器人：自研 6R、6-DOF 串联臂，后 3 轴相交形成球形腕；非冗余。关节 1–5 有机械范围，关节 6 可连续旋转。
4. 方法核心：Pieper 几何分解，先由目标 pose 求腕点和前 3 关节，再由姿态求腕部 3 关节；给出显式三角公式，提供隐式矩阵和显式公式变体。
5. IK 类型：解析几何闭式 IK，嵌入式 C++/平台无关实现；不依赖迭代优化。
6. Multiple solutions：每个 pose 明确 2^3=8 个组合（肩/肘朝向及腕部半周等价），测试中生成全部 8 个，再按当前构型最小角差选一解。
7. 分支：有明确的肩、肘、腕离散分支，但没有沿 path 的 branch tracking/switching 规则；评估只是每个 pose 选最近解。
8. 奇异性：分析肩部和腕部奇异检测，最大误差来自奇异附近；阈值可关闭。没有奇异穿越或连续 branch 证明。
9. 约束：报告机械关节范围、连续第六关节；实验为数学能力测试时明确忽略碰撞和 joint limits。未处理速度、加速度、力矩。
10. 碰撞：未实现；作者把 distance checking、collision detection/avoidance 列为未来目标。
11. 层级：pose-level IK；没有 path/trajectory 求解，只有随机 pose 验证。
12. 离散性：10000 个随机关节样本经 FK 生成目标 pose，再逐 pose 求 IK；无路径采样连续性实验。
13. 连续性/执行保证：闭式公式给出数学候选和浮点误差统计；最近角差选择的离散输出不是连续性保证，也不涵盖限位/碰撞执行。
14. Offline/online：嵌入式在线单 pose 求解，测试板上微秒级；离线 MATLAB/PC 随机评估。
15. Simulation/real robot：MATLAB/PC 仿真 + 嵌入式板执行 IK 计算；论文声称可用于控制并做了板上实验，但没有展示完整真实机械臂运动轨迹。
16. 主要实验：10000 随机 pose；嵌入式显式 variant 2 平均误差约 3.20×10^-15 rad、252 μs，隐式 variant 2 3.05×10^-15 rad、313.7 μs；IKFast 153.99×10^-15 rad、1856.2 μs。99%最大关节误差低于 10^-13 rad，最坏低于 10^-10 rad。
17. 贡献：面向嵌入式平台的简单几何 6R IK，明确 8 解结构，并同时报告 PC/板上精度和时延。
18. 局限：特定球腕 anthropomorphic 架构；忽略碰撞/限位的主随机测试；最近解选择不是 path branch 管理；奇异附近误差增大；无速度/加速度/轨迹保证。
19. Future work：作者明确提出距离检查与碰撞检测/避障、微分运动学、路径和轨迹规划以实现平滑 TCP 运动。
20. TCIK 一句话：8 分支闭式 pose IK 在嵌入式上很快很准，但论文没有把“每点选择最近解”提升为连续路径分支保证。

证据：§§4–5 几何分解和 8 解；§6.1–6.4 测试、奇异阈值和结果；§§7–8 讨论/未来工作。
