# Rank 95 — A Closed-Form Inverse Kinematic Analytical Method for a Humanoid Seven-DOF Redundant Manipulator
状态：READ_COMPLETE
全文：[MDPI HTML/full-text index](https://www.mdpi.com/2075-1702/14/4/395)；Space Frontiers 镜像核对正文段落。
1. 基本信息：Guojun Zhao, Ben Ye, Yunlong Tian, Juntong Yun, Du Jiang, Bo Tao；2026；Machines 14(4):395；DOI 10.3390/machines14040395。
2. 具体问题：7-DOF 人形冗余臂的无限 IK 解在严格关节限位下形成多个不连通 arm-angle 区间，如何解析描述可行域并高效选择高质量解。
3. 机器人/DOF/冗余：7 个转动关节，肩部 3R、肘部 1R、腕部 3R，肩/腕为球腕；相对 6D 位姿任务 1 个冗余 DOF。
4. 方法核心：引入 arm-angle ψ 和全局肩/肘/腕构型参数，完整推导前 3 关节参考平面关系；分类构造受限 ψ 的多个可行不连续区间，再将冗余优化降为区间上的一维目标搜索。
5. IK 方法/求解器：闭式几何/解析 IK + derivative-free 一维 interval search；目标组合归一化位姿误差与 minimum-joint/中间限位代价。
6. multiple IK solutions：是；ψ 连续自运动、全局构型参数和三角反解共同形成多解/多分支。
7. branch selection/tracking/switching：显式全局构型参数可识别分支，搜索多个不连续可行区间；但沿 pose-varying trajectory 的 branch tracking 尚未实现。
8. singularity avoidance/crossing/transition：讨论 arm-angle/算法奇异及分支边界，但未给出奇异穿越保证；实验重点是可行区间和干涉规避。
9. joint constraints：核心是逐关节位置限位，显式构造 ψ 可行域并在目标中远离限位；未处理速度、加速度或扭矩约束。
10. collision/obstacle：未做一般障碍规划；硬件实验报告无连杆干涉，属于验证性检查。
11. 层级：pose-level 解析解加简单轨迹跟踪优化。
12. sampled/discrete path：随机目标姿态和离散轨迹实验，ψ 域区间搜索本身是离散/区间采样式。
13. 连续性/可执行性保证：作者明确指出未来要加入 configuration continuity；当前没有跨区间连续性保证，区间边界可能出现构型跳变。
14. offline/online：解析推导离线，一维搜索面向快速在线 IK。
15. simulation/real：随机姿态仿真、对比实验和真实平台关键构型硬件验证。
16. 主要实验和结果：轨迹跟踪误差稳定且无干涉；随机目标比较显示误差分布更集中、平均计算时间更短、成功率更高。文章强调 interval-based 方案比纯局部或智能优化更能覆盖断裂可行域。
17. 主要贡献：完整化 7-DOF humanoid arm-angle 解析关系、显式全局构型/分支参数、断裂可行域建模和一维高效冗余优化。
18. 主要局限：未实现 pose-varying configuration continuity、动态约束、一般障碍和全局奇异处理；实机仅 proof-of-concept。
19. 作者 future work：配置连续性、随姿态变化的轨迹，以及动态约束。
20. TCIK 一句话：它把 joint-limit-induced disconnected branches 解析化并可控选择，但作者明确把连续 branch tracking 留作未来工作。
证据：MDPI/镜像全文的 Sec. 2–8、arm-angle 可行域、实验与 Conclusions。
