# Rank 54 — Singular Configuration Analysis and Singularity Avoidance with Application in an Intelligent Robotic Manipulator

状态：READ_COMPLETE

全文：[出版版 PDF](https://pdfs.semanticscholar.org/7fca/f86b7138cbae8be3f6d10153a655e784f3c6.pdf)，本地 tmp/papers/054.pdf；读取 Sections 1–6、算法和结果讨论。PDF 存在重复文字层，按正式 17 页正文核对。

1. 信息：Helin Wang、Ziqiang Zhou、Xianyou Zhong、Qijun Chen；2022；Sensors 22(3):1239；DOI 10.3390/s22031239。
2. 问题：JACO2 奇异构型条件及不同任务速度要求下的避免策略。
3. 机器人：Kinova JACO2，7R，完整位姿任务一维冗余。
4. 核心：分块腕 Jacobian 分析内部、边界和腕奇异；比较冗余优化、DLS、奇异一致性变速。
5. IK：固定 θ3 的解析 IK 加一维贪心搜索；数值伪逆加零空间项；DLS 自适应最小奇异值阻尼。
6. 多解：解析参数化冗余解，按相邻 q 加权平方差选解；没有认证枚举全部连续解。
7. 支路：相邻解成本和零空间调节，不含离散 branch 标签或全局 branch switching 规划。
8. 奇异：内部奇异可通过冗余优化回避；边界/腕奇异未必能这样回避。变速法以余子式/增广路径参数处理，不能视为任意奇异均可安全跨越。
9. 约束：解析候选限位；变速系数参考最大关节速度；未处理加速度硬约束。DLS 实验速度受限是该例结果。
10. 碰撞：未处理，列为 future work。
11. 层级：路径跟踪及局部速度控制，包含时间和控制周期。
12. 离散：数值迭代与离散控制；实验有插入中间点、0.01 s 控制周期和0.1 s绘图采样。
13. 保证：给运动学公式和仿真；DLS 带偏差，变速法在模型条件下保持路径。没有碰撞、动力学或全工作空间安全证明。
14. 时机：面向逐周期控制；报告平均求解时间，不是硬实时最坏界。
15. 验证：MATLAB 仿真，未报告本文实机验证。
16. 结果：数值/解析平均 2.1/1.4 ms；z 方向往返例未处理约4.65 s突变，DLS速度低于1.5 rad/s但误差增大；变速例更平稳并降低路径偏离。比较段“数值比数值慢三倍”原文笔误不据此推新结论。
17. 贡献：针对该结构的奇异条件与按任务速度要求选择避奇异策略。
18. 局限：参数敏感；冗余法不能解决全部奇异；安全结论超出仿真和运动学证据范围。
19. 作者展望：其他传感器安全监测、重规划避碰、按操作者状态调节和柔顺控制。
20. TCIK：表明奇异附近保持几何路径与保持末端速度是不同要求，连续执行仍需明确速度与误差边界。
