# Rank 100 — Multi-Solution Inverse Kinematics for Robotic Manipulators via Permutation-Invariant Set Prediction
状态：READ_COMPLETE
全文：[author full-text HTML/PDF](https://www.researchgate.net/publication/407016674_Multi-Solution_Inverse_Kinematics_for_Robotic_Manipulators_via_Permutation-Invariant_Set_Prediction)。
1. 基本信息：Duc Tien Nguyen, Van Thanh Tri Nguyen, Truong Do, Vu Linh Nguyen；2026；IEEE Robotics and Automation Letters，accepted May 2026；DOI 10.1109/LRA.2026.3703280。
2. 具体问题：6-DOF IK 本质是无序多解集合；单输出学习会均值化，多头网络又缺少跨姿态 branch correspondence，如何一次预测多分支并执行连续轨迹。
3. 机器人/DOF/冗余：UR3，6 个转动关节、非冗余但具有有限多分支 IK；真实轨迹作为执行数据。
4. 方法核心：多头生成器一次输出 K=8 个 q；用 Hungarian bipartite matching 的 permutation-invariant set loss 加 executed-branch inclusion loss 训练，再用 picker 选与上一时刻 q* 最近的候选。
5. IK 方法/求解器：学习式 fixed-cardinality set prediction；监督集由 analytic branch seeds + Levenberg–Marquardt refine + FK tolerance/joint-limit filtering 构建。
6. multiple IK solutions：明确是；每个姿态监督 8 个无序可行解，一次 forward pass 恢复多分支。
7. branch selection/tracking/switching：是；picker 按 wrapped joint distance 与前一已执行 q 选择，促进 temporal branch consistency；不强行建立全局 branch ordering，因而可在候选集合变化时切换。
8. singularity avoidance/crossing/transition：监督候选经过 FK tolerance 和关节限位过滤；没有显式 singularity penalty/穿越证明，学习选择主要针对平滑执行。
9. joint constraints：候选生成与过滤包含 joint-limit constraints；没有速度/加速度/扭矩硬约束。
10. collision/obstacle：未报告碰撞/障碍约束。
11. 层级：pose-level 多解预测 + trajectory-level 连续选择/跟踪。
12. sampled/discrete path：是；真实 UR3 时间序列和逐帧候选集合。
13. 连续性/可执行性保证：picker 的离散最近候选给出经验性的 joint sequence smoothness 和 branch consistency，真实机器人验证可执行；没有连续时间或全局拓扑保证。
14. offline/online：离线生成监督和训练，在线一次前向生成 8 候选并 O(K·6) 选择。
15. simulation/real：真实 UR3 trajectories、真实机器人执行验证；非纯仿真。
16. 主要实验和结果：与 single-output、fixed-assignment multi-head 及 multi-start numerical IK 比较；作者报告 set fidelity、branch coverage、轨迹重建和 task-space tracking 改善，且相对多起点数值 IK 具有更低推理延迟。完整 HTML 明确说明 8 解、Hungarian loss 和 continuity-aware picker。
17. 主要贡献：把 permutation-invariant 多分支监督与执行分支 inclusion、最近前态选择整合，连接“预测多解”与“可执行连续轨迹”。
18. 主要局限：UR3 单一机构、固定 K=8；预测质量受解析/LM 监督集影响；无碰撞、速度/加速度和数学连续性保证。
19. 作者 future work：全文未给出独立 future-work 清单；可确认的范围限制是固定分支数和单一 UR3，不将扩展方向冒充作者承诺。
20. TCIK 一句话：这是本批最直接的 learned multi-branch + branch tracking 工作，但连续性仍是离散最近候选的经验保证。
