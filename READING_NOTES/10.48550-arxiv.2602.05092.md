# Rank 96 — A Framework for Combining Optimization-Based and Analytic Inverse Kinematics
状态：READ_COMPLETE
全文：[arXiv PDF](https://arxiv.org/pdf/2602.05092)。
1. 基本信息：Thomas Cohn, Lihan Tang, Alexandre Amice, Russ Tedrake；2026；arXiv:2602.05092。
2. 具体问题：标准优化 IK 把高度非线性的 FK 等式、碰撞和稳定约束同时交给优化器，容易失败；如何用已知解析 IK 作为变量变换提高约束 IK 成功率。
3. 机器人/DOF/冗余：7-DOF KUKA LBR iiwa、10-DOF KMR iiwa 移动臂、PR2 双臂（两条 7-DOF 臂+底座/躯干）、31/34-DOF Hubo，以及 2D/3D 逐步加关节链；覆盖冗余和非冗余。
4. 方法核心：把 q 和 FK 等式消去，以末端位置/姿态、自运动连续参数 ψ 和离散 manifold 参数 κ 作为优化变量，解析 IK 输出 q；加入 reachability probing 函数避免 arccos/clipping 域外。
5. IK 方法/求解器：手工/自动兼容的解析 IK 映射作为 change of variables；外层比较 IPOPT、SNOPT、NLOPT augmented Lagrangian，并以 sampling/Global-IK 作基线。
6. multiple IK solutions：是；解析 IK 的离散 self-motion manifold κ 与连续 ψ 显式表示多个解族。
7. branch selection/tracking/switching：可固定 κ 或枚举 κ，并实验研究不同 branch 的成本；没有时间序列自动 branch tracker，但 κ 变量使选择显式。
8. singularity avoidance/crossing/transition：解析映射通过 reachability probes/内部裁剪避开域外，奇异配置按 measure-zero 讨论；不提供穿越奇异面的轨迹保证。
9. joint constraints：显式 q 下/上限，且可加稳定性、碰撞等非线性约束；未系统处理速度/加速度/jerk。
10. collision/obstacle：是；KUKA/移动臂/双臂实验含桌面、货架、箱体的 collision-avoidance，Global-IK 用自由空间近似作基线。
11. 层级：pose-level constrained IK，扩展到 grasp selection、mobile/bimanual configuration 和 humanoid stability；不是时间轨迹生成器。
12. sampled/discrete path：目标姿态和随机初值是离散实验；无路径采样器或时间参数化。
13. 连续性/可执行性保证：把解析 IK 约束精确地嵌入优化并改善可行性，但 κ 固定意味着可能漏掉其他流形；无全局连续轨迹或硬件执行证明。
14. offline/online：外层优化离线/在线均可调用，论文为离线仿真基准。
15. simulation/real：多机器人模型仿真，无真实硬件实验。
16. 主要实验和结果：在 100 个随机目标×100 个初值的桌面 7-DOF 任务中，新 formulation 的 IPOPT/SNOPT/NLOPT 成功率普遍提高；桌面、抓取、移动和双臂任务中对碰撞约束更稳。新 formulation 牺牲部分成本最优性，但在 31-DOF Hubo 稳定性仍约 96–97% 成功；随冗余增大，求可行解保持稳定而优化成本变难。
17. 主要贡献：用解析多解 IK 消除 FK 等式，统一处理自运动、离散 branch、碰撞与稳定性约束，并跨多种非线性优化器实证比较。
18. 主要局限：依赖可微解析 IK、固定 κ 可能漏解；新变量空间的成本函数非凸且高冗余时迭代数急增；自动生成 IK 兼容性仍是工程问题。
19. 作者 future work：让 IKFast/IK-Geo 等自动生成代码支持可微映射；研究无解析 IK 机械臂的数值/学习映射；扩展更高冗余和复杂约束。
20. TCIK 一句话：这是将解析多解作为优化坐标、同时处理碰撞和分支参数的强约束 IK 框架，但尚未给出路径级 branch continuity。
证据：本地 arXiv PDF Sec. III–VI、Tables I–III、桌面/移动/双臂/Hubo 实验与 Discussion。
