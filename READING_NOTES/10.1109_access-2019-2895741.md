## 研究问题与机器人假设

作者以 KUKA LBR iiwa 14 R820 为模型，利用肩部和腕部球形关节结构，将七自由度臂抽象为肩点 S、肘点 E、腕点 W 和末端 T。给定 6D 末端位姿后，SEW 三角形的边长固定，E 沿 SW 轴的圆周自运动；用肘角 `theta` 表示这一个连续冗余自由度。几何解析逆解再引入 elbow、arm、wrist 三个正负标志，从而表示每个冗余角下的离散多解（Sec. II, Figs. 1–8, Eqs. (1)–(24)）。

## 解析 IK 与分支选择

1. 给定末端位姿先求腕点，再由肩肘腕三角形余弦定理求关节 4 的两个 elbow-up/down 解；肘角 `theta` 控制 SEW 平面的绕 SW 自运动。肩部 3R 和腕部 3R 分别以 Z-Y-Z 类球铰参数化，几何旋转矩阵可解析恢复各关节角。
2. 每个末端位姿和肘角下，elbow、arm、wrist 符号组合产生 8 组解析 IK。`arm` 表示肩部构型左右/正负 `q2` 分支，`wrist` 表示腕部 flip 状态，`elbow` 区分肘在 SW 两侧。离散标志是解支路标签，连续参数则是 `theta`。
3. 作者指出映射连续末端路径时不能逐点任意改变正负标志，否则关节角会跳变。工作空间按 arm/wrist 等构型分块，路径应留在对应分块或只通过表 2 所列可连续连接的边界。正文明确给出：肘标志可在 `q4=0` 或其附近切换而让 `q4` 连续；但 `q2≈0` 附近不能据此随意翻转 arm 标志，因为 `q1` 或 `q3` 可能跳变或导致越限（Sec. II-D, Table 2–3, pp.5–6）。这体现了 branch compatibility 条件，但不是通用的在线 branch graph 算法。
4. 解析几何构造有特殊退化：W 点落在基坐标 Z 轴时，构造肩部坐标系的叉积为零，作者用固定 Y 向量作特例处理（Sec. II-C, Fig. 8）。这属于特定参数化公式的数值/几何退化处理；文中没有给出完整机器人奇异流形穿越定理。

## 关节限位和避障

- **硬关节限位区间**：把由 `theta` 得到的各关节角映射写成正弦/余弦或正切关系，逐个解出满足关节上下界的 `theta` 区间，再求交集；通过此区间可枚举指定末端位姿下满足限位的解。示例交集为 `[-2.1080,-0.2680] ∪ [0.1828,1.8828]` rad（Sec. III, Eqs. (25)–(34), Figs. 11–13, pp.6–8）。这处理的是静态角度范围，不包含速度、加速度、力矩或碰撞。
- **碰撞过滤**：固定末端位姿时，肩腕位置固定，肘点沿圆周动；作者在 `theta∈[-pi,pi]` 上离散采样，对 SE、EW 连杆进行障碍碰撞检测，形成无碰撞角区间，再与关节限位区间相交。示例使用长方体和圆柱体障碍，报告一段避障角区间约 `[1.5584,2.1784]` rad（Sec. IV, Eqs. (35)–(40), Figs. 14–17, pp.8–10）。离散角度碰撞检测没有连续碰撞检测或区间覆盖证明，障碍过窄或角度步长不足可能漏检。

## 仿真与结果

- MATLAB Robotics Toolbox 建立 iiwa 模型。路径仿真令末端走闭合椭圆：`x=0.3`，`y=0.2+0.2 cos(alpha)`，`z=0.4+0.2 sin(alpha)`，`alpha∈[-pi,pi]`；末端姿态约绕 X 轴旋转 60°。作者报告末端椭圆闭合、姿态符合目标，解析 IK 没有数值漂移。该结果来自离散 alpha 取样的运动学仿真，不是硬件周期运行或 q(0)=q(T) 的定量闭合误差验证（Sec. V-A, Figs. 18–21, pp.10–11）。
- 通过 arm/wrist 标志切换可处理关节越限/±180° wrap 的特定多解情形；另用一个超限起始构型逐点扫 `theta` 并按图线/表格得到限位可行段。该例依赖对单个位姿的肘角扫描，未报告角度采样间隔或误差界（Sec. V-A–B, Figs. 20–26, Tables 5–6, pp.10–12）。
- 避障仿真使用圆柱和长方体障碍；比较章节在抓取/障碍场景中将传统规划结果与本文方法的路径图对照。作者称传统例显示第 248、363 次调整的路径仍有多个跳点；本文例显示第 25、16 次调整结果更平滑、调整次数较少。这里是图示和调整次数比较，没有运行时间、轨迹跟踪误差、统计重复试验或实机结果（Sec. V-C–VI, Figs. 27–30, pp.12–13）。

## 对本综述主题的证据判断

- **重要核心相关文献**：它显式保留冗余连续参数加三类离散 IK 解标签，研究了沿连续末端路径选择离散多解以生成连续关节角，并给出可切换与不可随意切换的支路边界。这比每点独立求解或仅报告 warm start 更直接涉及 branch tracking。
- **奇异点转迁**：文中将 `q4=0` 附近作为 elbow-up/down 的连续接合条件，并限制其它离散 sign flips；这提供了特定肩肘腕结构的代数支路衔接规则。它没有分类完整 Jacobian 奇异集、分析秩降附近速度/导数有界性、处理多奇异分支交会，也没有实验证明跨奇异的稳健性。解析坐标系退化特例不应当作机器人奇异转迁证明。
- **周期/轨迹一致性**：末端闭合椭圆仿真和无关节漂移描述支持对一条离散采样闭合任务的连续性观察；论文没有把首末关节相等作为优化约束，也没有系统测量周期闭合误差、速度/加速度连续性或跨周期同一分支复现。应归为 branch-selection / path-continuity 的几何方法，不是 repeatable IK 闭环保证。
- **关节限制与碰撞**：静态关节区间通过解析不等式映射，障碍区间通过对冗余角采样和碰撞测试求得；没有动态限位、速度/加速度或力矩约束，也没有连续碰撞安全保证。
- **证据强度**：同行评审期刊、推导较完整；结果只有 MATLAB 几何仿真。文中声称“complete feasible”是给定姿态和其离散化/特定几何假设下的逆解集合求取目标，不应扩大解释为全路径连续可行、动力学可执行或实机已验证。
