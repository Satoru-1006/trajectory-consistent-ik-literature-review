# Rank 98 — Many-RRT*: Robust Joint-Space Trajectory Planning for Serial Manipulators
状态：READ_COMPLETE
全文：[arXiv PDF](https://arxiv.org/pdf/2603.04547)。
1. 基本信息：Theodore M. Belmont, Benjamin A. Christie, Anton Netchaev；2026；arXiv:2603.04547。
2. 具体问题：任务空间目标的 FK 逆像可能包含多个关节目标，单个 IK goal 会把 RRT 引向不可达或高成本分支；如何在同一预算下并行利用多目标。
3. 机器人/DOF/冗余：6-DOF UR10e 和 7-DOF Franka Panda，配置空间规划；7-DOF 具有冗余，6-DOF 也有多重对称 IK。
4. 方法核心：Many-RRT* 扩展 RRT*-Connect，为多个 IK 解各建一棵 goal tree，与一棵 start tree 并行生长；start tree 以 exploration/exploitation 概率从所有树和 Cfree 采样并连接。
5. IK 方法/求解器：多初值 SQP 优化 IK，目标是 FK 误差加与 seed 的距离并施加 qmin/qmax；解集去重后作为多个 goal。
6. multiple IK solutions：是，明确生成并行多 IK solutions，实验固定 10 个解、11 棵树。
7. branch selection/tracking/switching：不跟踪时间 branch；通过并行 goal tree 隐式比较/选择可达分支，避免预先错误选择单一 IK。
8. singularity avoidance/crossing/transition：IK 迭代可能受 Jacobian 奇异影响；论文没有奇异规避或穿越策略。
9. joint constraints：IK 和配置空间边界含 joint position limits；未建模速度、加速度、动力学约束。
10. collision/obstacle：是；Cfree 碰撞自由配置和球体障碍环境贯穿 RRT 扩展/连接。
11. 层级：joint-space path-level 规划，最终用分段线性关节路径连接节点。
12. sampled/discrete path：是；RRT 节点、边和线性 waypoint 插值，未做时间参数化。
13. 连续性/可执行性保证：RRT* 具有渐近最优性/收敛论证，路径在 Cfree 的规划模型内；实际执行仍是线性插值，无速度/动力学和连续时间碰撞证明。
14. offline/online：采样规划可在线单查询；实验为离线 500 次基准。
15. simulation/real：仅仿真，AMD Ryzen 9 7950X，Table/Wall/Passage/Random 四类球障碍环境。
16. 主要实验和结果：每环境 500 trials、3000 iterations/3000 ms。6-DOF Random 中 Many-RRT* 成功率 100%（RRT* 1.4%、RRT*-Connect 1.6%），最终代价 12.97；7-DOF Random 96.8%，优于 5.0%/8.8%，并在相同时间总体约低 44.5% cost。简单 Table/Wall 中性能接近基线，复杂 Passage/Random 明显改善。
17. 主要贡献：把多 IK 逆像当作并行 bandit-like goal set，保留 RRT*-Connect 的快速连接和 RRT* 的渐近最优性。
18. 主要局限：并行树使节点总数/内存上涨，连接操作是主要瓶颈；IK 质量依赖初值，路径无动力学可行性/连续时间安全保证。
19. 作者 future work：进一步并行化 CONN_TREE，可转 GPU/NPU；摘要外未给出更具体的 IK continuity 计划。
20. TCIK 一句话：Many-RRT* 用并行多 IK goal 解决分支可达性选择，但没有 branch tracking、奇异处理或时间轨迹保证。
证据：本地 PDF 的 Problem Statement、Many-RRT* Algorithm 1、Table I 和 Conclusion。
