# Rank 64 — Inverse Kinematics and Path Planning of Manipulator Using Real Quantifier Elimination Based on Comprehensive Gröbner Systems

状态：READ_COMPLETE
全文：[arXiv v2 PDF](https://arxiv.org/pdf/2305.12451)；已读全文 §§1–6、Algorithms 1–7、Tables 1–2、Examples 1–3 与结论。

1. 基本信息：Mizuki Yoshizawa、Akira Terui、Masahiko Mikawa；2023，arXiv:2305.12451v2（11 July 2023，cs.RO）；DOI/arXiv 10.48550/arXiv.2305.12451。
2. 具体问题：对给定末端位置判断 IK 是否存在、计算实解，并对参数化直线路径验证整段可行性，避免对每个 waypoint 重复昂贵 Gröbner 基计算。
3. 机器人：LEGO Mindstorms EV3 的 3-DOF 位置型串联机械臂，仅 3 个转动变量 θ1、θ4、θ7；相对 3D 位置任务为非冗余。作者还讨论更高 DOF 扩展，但未实验。
4. 方法核心：把三角方程转成含 sin/cos 约束的多项式系统；用 Comprehensive Gröbner System（CGS）按末端参数分段，用 CGS-QE 与实根计数判断存在性，随后数值求根。对整条线段把路径参数 s 保留为参数，通过量词消去得到实解存在区间。
5. IK 类型：代数/半符号解析型 CGS-QE；CGS 预计算后每个 pose 数值求根。非零维理想时固定不唯一的 θ1=0，再求其余根。
6. Multiple solutions：实根计数明确识别多实根，但 Algorithm 1 多解时只接受求解器返回的第一组；不是完整候选集输出。
7. 分支：没有 branch 标签、branch tracking 或 switching；作者明确承认逐点首解可能导致关节序列不连续。
8. 奇异性：z 轴上的 x=y=0 会使 θ1 不唯一（非零维理想）；可求出某个代表解，但没有奇异分支穿越策略。未来建议用连通胞分解/可操纵性标准处理连续性。
9. 约束：路径示例用五次时间标度使末端起止速度、加速度为零，并讨论末端速度/加速度；未建模关节位置、速度、加速度、力矩硬约束，只有几何方程和可行域存在性。
10. 碰撞：未包含障碍或连杆碰撞模型。
11. 层级：pose-level 位置 IK、path-level 参数线段可行性和离散 trajectory 生成；不是完整动力学轨迹优化。
12. 离散性：Algorithm 6 按 t=0,…,T 离散调用 IK；Algorithm 7 对连续参数 s∈[0,1] 做代数存在性验证。实际关节序列仍是采样输出。
13. 连续性/执行保证：Algorithm 7 对该特定线段给出严格的“每个 s 存在实 IK”判定；不保证选出的第一根解形成连续 branch。作者给出明确反例：经过非零维理想点时 θ1 可能跳变。
14. Offline/online：CGS 和量词消去离线/预计算；每 pose 平均约 0.1068 s，作者认为可用于实时求解，但没有控制周期验证。
15. Simulation/real robot：1000 个随机末端位置的 Risa/Asir/PARI 计算，另有 EV3 相关实现/实验规划；本文报告的是计算机实验，没有实机运动闭环结果。
16. 主要实验：预计算 CGS 约 62.3 s；1000 点平均误差 1.6319×10^-12 mm、平均 IK 0.1068 s，较早版本 0.54/0.697 s 更快。线段 (10,40,80)→(40,100,20) 的 50 步路径规划约 3.377 s，去除无实点分段后约 2.246 s；连续可行性量词消去另需 CGS 485.8 s、MainQE 1.107 s。
17. 贡献：把 CGS-QE 从单点 IK 自动化扩展到实点分段、非零维情况和整条参数路径可行性验证，并给出可复现的代数算法。
18. 局限：多解只取第一解，不能保证 branch continuity；奇异/非零维点会造成 θ1 跳变；CGS 成本高；只处理 3-DOF 位置机械臂、线段路径，无碰撞/动力学/实机保证。
19. Future work：作者明确提出连续 IK 解选择、处理非零维点的连续关节序列、提升实时效率、推广一般多项式曲线和更高 DOF。
20. TCIK 一句话：CGS-QE 能严格证明特定几何路径逐点存在 IK，但作者自己明确指出“存在性”仍不等于首解序列的连续 branch。

证据：§§3–4 CGS-QE/Algorithms 1–5；§5.1 Algorithms 6、Example 2、Remark 12；§5.2 Algorithm 7、Example 3、Remark 14；§6 五项 future work。
