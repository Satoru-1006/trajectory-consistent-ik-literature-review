# Rank 97 — Actuator-Aware Inverse Kinematics with Joint-Limit Admissibility for Torque-Controlled Redundant Robots
状态：READ_COMPLETE
全文：[arXiv PDF](https://arxiv.org/pdf/2605.31436)。
1. 基本信息：Mohammad Dastranj, Mahdi Hejrati, Jouni Mattila；2026；arXiv:2605.31436。
2. 具体问题：对 torque-controlled 冗余机器人，IK 输出是下游扭矩控制器的 required velocity reference；如何同时保持任务、满足关节限位可容许性并生成控制器可跟踪的速度。
3. 机器人/DOF/冗余：7-DOF upper-limb exoskeleton，任务 twist 低于关节数，冗余；由 virtual decomposition control（VDC）扭矩层执行。
4. 方法核心：以 required joint velocity 和 task slack 为变量建立凸 QP；CBF-style 上下界限制速度方向，代价包含上一时刻速度一致性和按已知扭矩容量加权的 actuator compatibility。
5. IK 方法/求解器：微分 IK 的 convex quadratic programming；比较 PINV、DLS、null-space JLA 和 task-preserving QP。
6. multiple IK solutions：是，J(q)qdot=Vr 在 n>m 时有 n−m 个速度自由度；QP 从中选控制器兼容解，不枚举离散 branch。
7. branch selection/tracking/switching：没有离散 branch；上一时刻 qdot reference consistency 项提供局部时间跟踪，但无 branch ID/switching 机制。
8. singularity avoidance/crossing/transition：假设测试构型 Jacobian 满行秩；未提出奇异性穿越策略。
9. joint constraints：明确有 reference-level joint velocity admissibility 和机械限位方向约束；平台位置/扭矩限值用于计算指标，未作 plant-level 安全证明。
10. collision/obstacle：未处理。
11. 层级：在线 velocity-level IK，用于 trajectory tracking 的中间层。
12. sampled/discrete path：是；1 kHz 离散控制样本记录 25 s 轨迹。
13. 连续性/可执行性保证：QP 每步凸可解、速度边界有离散可容许性；没有连续时间硬件安全、位置积分无漂移或碰撞保证。
14. offline/online：在线中间层，实验在实时 VDC 闭环中运行。
15. simulation/real：真实 ABLE 7-DOF 上肢外骨骼/力反馈接口，MATLAB/Simulink 与 EtherCAT；不是纯仿真。
16. 主要实验和结果：相同 endpoint trajectory 和 VDC 控制器下，所提方法 required-velocity violation 为 0，Ipush=0.02110，低于 PINV 0.18949、DLS 0.17946、NS-JLA 0.53104、TP-QP 0.05877；RMS 位置误差 0.00614 m、姿态 0.01477 rad、扭矩范数 3.3582 Nm，均整体更平衡。相对 TP-QP 位置/姿态 RMS 分别下降约 29.6%/20.2%。
17. 主要贡献：把关节限位可容许性、执行器能力和下游控制器兼容性直接放进冗余 IK reference generation，而不改动扭矩控制器。
18. 主要局限：扭矩容量权重来自已知额定限制而非实测扭矩；结果是单一外骨骼轨迹，非 plant-level safety proof；无碰撞、branch 或奇异分析。
19. 作者 future work：论文结论未列出额外独立清单；明确范围是 controller-agnostic 中间层，需更多机器人/任务验证，不能把潜在扩展写成作者承诺。
20. TCIK 一句话：这是把关节限位和执行器可实现性带入在线冗余 IK 的实机 QP，但它解决的是速度选择而非多分支轨迹连接。
